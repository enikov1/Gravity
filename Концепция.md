🎮 Концепция игры: «Гравитация» (рабочее название)
Жанр и платформа
2D-триал с боковым скроллом, вдохновлённый Gravity Defied. Игрок управляет мотоциклистом, преодолевая процедурно сгенерированные трассы с холмами, трамплинами, обрывами и подвижными препятствиями. Платформа — Яндекс Игры (HTML5, десктоп + мобильные).

Ключевая механика
Физика — это геймплей. Мотоцикл состоит из двух колёс, соединённых constraint'ами (подвеска), и корпуса. Игрок управляет газом, тормозом и наклоном райдера. Неправильный угол на трамплине = падение. Основная сложность — баланс между скоростью и контролем.

Игровой цикл
Заезд → игрок проходит трассу за минимальное время / без падений.

Награда → монеты (внутриигровая валюта), звёзды за прохождение, разблокировка новых мотоциклов.

Прогрессия → улучшение характеристик байка (мощность, подвеска, сцепление) за монеты.

Ежедневные испытания → процедурно сгенерированные трассы с модификаторами (лёд, гравитация, туман).

Управление
Десктоп: стрелки / WASD.

Мобильные: экранные кнопки (газ, тормоз, наклон вперёд/назад).

⚙️ Процедурная генерация уровней
Подход: чанковая генерация на основе шума
Уровень генерируется не целиком, а чанками (сегментами) по мере продвижения игрока. Это критически важно для браузера — экономит память и позволяет создавать бесконечные трассы.

Алгоритм:

Базовый рельеф — генерируется через шум Перлина (или Simplex-шум). Высота точек рельефа определяется суммой нескольких октав шума с разной амплитудой. Это даёт плавные холмы и спуски.

Типы сегментов — каждый чанк имеет тип: «прямая», «трамплин», «обрыв», «волны», «платформы». Тип выбирается случайно с весами, зависящими от сложности (номер уровня).

Препятствия — на рельеф накладываются объекты: камни (статичные тела), бочки (динамические), подвижные платформы (кинематические тела), вращающиеся балки.

Коллизии — рельеф представляется как цепочка статичных тел Matter.js (сегменты полигонов). Для производительности используется poly-decomp для декомпозиции сложных форм на выпуклые полигоны.

Параметры генератора (сид):

seed — число, определяющее всю трассу (можно делиться с друзьями).

difficulty — 1–10, влияет на амплитуду шума, частоту препятствий, гравитацию.

length — количество чанков (для бесконечного режима — генерируется на лету).

Пример псевдокода:

javascript
function generateChunk(seed, index, difficulty) {
  const noise = new SimplexNoise(seed + index);
  const points = [];
  const baseY = 400;
  const amplitude = 80 + difficulty * 20;
  const frequency = 0.005 + difficulty * 0.001;

  for (let x = 0; x < CHUNK_WIDTH; x += 10) {
    const y = baseY + noise.noise2D(x * frequency, 0) * amplitude;
    points.push({ x, y });
  }

  const type = pickSegmentType(difficulty);
  if (type === 'ramp') addRamp(points);
  if (type === 'gap') addGap(points);

  return { points, obstacles: generateObstacles(points, difficulty) };
}

🏗️ Физика мотоцикла: детали реализации
Мотоцикл — это составное тело из трёх частей:

Заднее колесо — динамическое тело (круг), высокое трение.

Переднее колесо — динамическое тело (круг), высокое трение.

Корпус (шасси) — динамическое тело (прямоугольник), соединяющее колёса через constraint'ы с заданной жёсткостью и демпфированием.

typescript
// Упрощённый пример создания мотоцикла
const rearWheel = this.matter.add.circle(x, y, 20, {
  friction: 0.9,
  restitution: 0.1,
  density: 0.05
});

const frontWheel = this.matter.add.circle(x + 60, y, 20, {
  friction: 0.9,
  restitution: 0.1,
  density: 0.05
});

const chassis = this.matter.add.rectangle(x + 30, y - 10, 60, 20, {
  density: 0.1
});

// Подвеска: соединение колёс с шасси
this.matter.add.constraint(chassis, rearWheel, 0, 0.8, {
  pointA: { x: -30, y: 0 },
  stiffness: 0.9,
  damping: 0.1
});
this.matter.add.constraint(chassis, frontWheel, 0, 0.8, {
  pointA: { x: 30, y: 0 },
  stiffness: 0.9,
  damping: 0.1
});
Управление:

Газ → применяется крутящий момент (setAngularVelocity) к заднему колесу.

Тормоз → снижение угловой скорости обоих колёс.

Наклон → применение силы к шасси (вперёд/назад).

Критический момент: для стабильной физики необходимо использовать фиксированный временной шаг (fixed timestep) с аккумулятором. Matter.js по умолчанию использует переменный шаг, что может привести к нестабильности при просадках FPS.

typescript
// В update(delta)
this.accumulator += delta;
while (this.accumulator >= FIXED_STEP) {
  this.matter.world.step(FIXED_STEP);
  this.accumulator -= FIXED_STEP;
}
📦 Интеграция с Яндекс Играми
Обязательные требования
SDK Яндекс Игр должен быть встроен в игру.

Платежи только через SDK, без внешних покупок.

Авторизация только через Яндекс ID (запрашивается через SDK).

Реклама только через SDK (YAN — Рекламная сеть Яндекса).

💎 Ключевые рекомендации
Начните с Matter.js — для прототипа его более чем достаточно. Если физика мотоцикла окажется нестабильной (дрожание, проскок колёс), переходите на Phaser Box2D — это даст эталонную точность Box2D v3 с производительностью, оптимизированной для браузера.

Используйте poly-decomp для декомпозиции сложного рельефа на выпуклые полигоны — это обязательное требование Matter.js для стабильных коллизий.

Фиксированный временной шаг — критически важен для предсказуемой физики. Без него игра будет вести себя по-разному на разных устройствах.

Чанковая генерация — не генерируйте весь уровень сразу. Это сэкономит память и позволит создавать бесконечные трассы.

Тестируйте на реальных мобильных устройствах — Яндекс Игры требуют корректной работы на смартфонах. Управление должно быть адаптировано под тач.

Если нужно углубиться в какой-то конкретный аспект — физику подвески, алгоритм генерации или интеграцию SDK — спрашивайте, разберём детально.
